## 安装说明

- 需要 Android 8.0（API 26）及以上；
- APK 已使用 **mingapp** 证书签名（APK Signature Scheme v2），可正常安装与更新；
- 首次安装未知来源应用时，请在系统设置中允许「安装未知应用」。

## 校验

安装包 SHA-256 指纹见各 Release 的说明。
